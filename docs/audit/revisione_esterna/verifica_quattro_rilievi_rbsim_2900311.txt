### 2. Direct state writes in `effects.py` — correct, with a counting caveat

My AST count found **126 attribute assignment targets** including augmented assignments, **239 calls** to `append`, `extend`, `remove`, `pop`, `insert`, or `clear`, and **47 subscript writes or deletes**. Those are source sites. Some modify temporary lists or fresh objects. Even restricting the count to expressions rooted directly at `ctx.loop.gs`, `ctx.actor`, or `ctx.opponent` gives **59 potentially mutating sites** before following aliases such as `gs` and `ap`.

The important part is what handlers own. `_take_over_spell` directly changes a chain item’s controller and clears its declared choices. `_conquer_return_this_turn` writes a persisted `id(unit)` straight into game state, the same pattern behind the clone failures. An API migration that only replaces private method calls can leave both mutations exactly where they are.

**Severity — Medium-high**, above file size and private-call counts. I’d track ownership of chain, zone, and timing mutations as an explicit refactor criterion. The confirmed clone defect still ranks **High**. [Spell takeover](https://github.com/califhornya/rbsim/blob/2900311/riftbound/core/effects.py#L715) · [Conquer-return state](https://github.com/califhornya/rbsim/blob/2900311/riftbound/core/effects.py#L1408)

### 3. Tests depend on private methods — correct in scale

Matching private `GameLoop` method names against `tests/**/*.py`, the broad regex `\.(_\w+)` gave **113 files, 142 names, and 1,722 matches**. Counting AST call sites gave **111 files, 133 names, and 1,691 calls**. Both match by name and can include a different receiver with the same method name. The regex also picks up comments and strings. Two files entered its count solely through textual mentions.

**Severity — Medium**, as a migration cost. Removing or changing a private entry point can break valid behavior tests. Moving its implementation while preserving the entry point can keep them green. Tests that override the method need more care. The legality probe, for example, overrides `_apply_action` to inspect actual play, so a new execution path can bypass the probe while its method still exists. [Counting method in the plan](https://github.com/califhornya/rbsim/blob/2900311/docs/PIANO_MOTORE.md#L351) · [Legality probe](https://github.com/califhornya/rbsim/blob/2900311/tests/test_legality.py#L65)
